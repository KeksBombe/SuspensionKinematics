Mesa llvmpipe -- the software OpenGL renderer shipped with the Windows build
as opengl32sw.dll, which Qt falls back to on a machine whose driver cannot
give it OpenGL 3.3 (a virtual machine, a remote desktop). The binary is the
one the Qt installer ships; it reports itself as Mesa 11.2.2 built against
LLVM 3.6.2. It is not used on Linux, where the system's own OpenGL is.

Mesa source:  https://gitlab.freedesktop.org/mesa/mesa
LLVM source:  https://github.com/llvm/llvm-project
